# Supporto

Per iniziare consulta [Primi passi](docs/GETTING_STARTED.md), [FAQ](docs/FAQ.md) e i README dei moduli.

- **Bug riproducibile:** apri una [segnalazione](https://github.com/pxxyco/untitled_ea_project/issues/new/choose) con versione, ambiente, passaggi e risultato atteso.
- **Nuova funzione:** usa il modello di proposta spiegando il bisogno e l’effetto sul flusso utente.
- **Domanda:** usa il modello Domanda / aiuto. Se il team attiva Discussions, le domande generali potranno essere spostate lì.
- **Vulnerabilità o dati sensibili:** segui [SECURITY.md](SECURITY.md).

Il supporto è gestito dal gruppo di progetto, senza SLA. Non allegare database, keystore, password, carte reali o log non ripuliti.
